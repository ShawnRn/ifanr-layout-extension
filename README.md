# 爱范儿一键排版 (Lark2Pad) v1.14.0

## 最新更新（v1.14.0：全面集成 LiquidConvert / Lark2Pad 全量排版能力）

- **全量排版能力对齐**：
  - **微信公众号排版**：包含爱范儿 / AppSo 顶部 Banner 动态适配、`<h3>` 标题层级计算（字号 24/22/20/18px、上边距 62/42px、左右 padding 14px、颜色 `#FD4606`）、正文（15px / 27px 行高）、引用块（左侧 4px 灰边）、图注（`图｜...` 12px 浅灰）及列表规范。
  - **文章尾部 Meta 元信息行识别**：自动识别 `作者`、`编辑`、`声明`、`题图`、`插图`、`封面`、`策划`、`排版`、`免责声明`、`文` 等，统一赋予 12px 加粗字体，组内末项保留 24px 下边距，与官方规范 100% 对齐。
  - **微信官方素材防丢失保护**：底部 5 斜线橙色分隔符、招聘卡片、二维码素材完整附带 `data-src` / `data-type` 属性，且微信官方图床（`mmbiz.qpic.cn` / `weixin.qq.com`）加入白名单杜绝重转 Base64，彻底解决公众号存盘后分隔符或底栏消失的问题。
  - **标准 Etherpad (Pad) HTML 格式支持**：支持生成标准的 Etherpad HTML 与 Markdown，包含顶部/底部 Banner、标题、正文、图片与作者编辑行。
- **弹窗体验升级（多端极速复制）**：
  - **「复制到公众号」**：一键将高质量公众号富文本写入系统剪贴板，可直接在微信公众号编辑器中 `Cmd+V` / `Ctrl+V` 粘贴，秒速生效。
  - **「复制到 Pad」**：一键将 Etherpad 标准 HTML / Markdown 写入系统剪贴板，方便在 Etherpad 或协同编辑器中粘贴。
  - **「一键注入公众号」**：在公众号编辑页中保留逐张插入图片与自动确认托管的自动化流程。
- **性能与流畅度优化**：
  - 原生 `navigator.clipboard.write([new ClipboardItem(...)])` 异步极速写入，响应延迟 < 50ms；
  - 官方 CDN 直连跳过转码，降低内存开销。

## 历史更新（v1.13.0）

- 图片托管提速：所有图片一次性快速写入正文骨架，微信并发上传，不再逐张阻塞等待；最后统一确认，未托管的图片原位替换为补图标记。
- 修复「0 张待补」误报：现在同时统计超限图和托管失败图，提示会写明两类数量。
- 弹窗加宽到 400px，消除右侧空白。

## 更新（Lark2Pad 图片增强 + 逐张托管）

- 静态图片全部按 Lark2Pad 规则处理：统一缩到 1280px 内、可选 2% 连续圆角、按画质档位重编码，动图保持原样。图片体积和微信托管压力显著下降。
- 公众号写入改为「先写正文骨架，再逐张插入图片」：不再把整篇 Base64 内容一次性塞进编辑器，避免大段粘贴导致的卡顿；每张图片插入后单独等待微信托管确认，失败时原位保留补图标记。
- 排版超时按图片数量动态调整（每张约 5 秒，上限 3 分钟），不再固定 45 秒。
- 弹窗新增「图片圆角」「图片智能处理」开关，可随时切换；切换后重新收录即可。

## 安装或升级

1. 解压安装包，保留整个文件夹。
2. Chrome 打开 `chrome://extensions/`。
3. 打开右上角“开发者模式”。
4. 已安装旧版：找到“爱范儿飞书到微信排版 POC”，点击“移除”，再选择“加载已解压的扩展程序”。
5. 选择解压后的 `extension` 文件夹。
6. 已打开的飞书和公众号页面各刷新一次。

## 使用新增内容整理

1. 先完成正常的一键排版。
2. 在公众号正文中补字、按 Enter 新增段落或粘贴新内容。
3. 如果新段落出现嵌套缩进、字号或字体继承异常，打开插件。
4. 点击“整理新增内容”。
5. 插件只整理后来新增且没有爱范儿语义标记的文字块，不主动改变已有标题、引用、图注和图片。

## 图注写法

建议在飞书中把图注放在图片下一行，并使用明显前缀，例如：

- `图 | charlesdeluvio @ Unsplash`
- `图源：Apple`
- `摄影：张三`
- `Photo by xxx`

没有明显图注特征的普通短段落不会自动改成图注。
