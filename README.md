# 爱范儿一键排版 (Lark2Pad) v2.0.0

专为爱范儿与 AppSo 团队打造的高保真飞书排版浏览器扩展。支持一键全自动提取飞书云文档全文、100% 原始高清原图直通、微信公众号/Pad 双平台格式转换与智能一键直注。

---

## ✨ 核心特性（v2.0.0 重磅升级）

1. **同级双大主按钮设计（0 滚动）**：
   - 顶部首屏左侧：**【一键读取转换】**（极速全自动抓取飞书全文与高清原图并完成转换）
   - 顶部首屏右侧：**【一键注入公众号 / Pad】**（智能自适应大按钮，直注目标编辑器）
   - 中间快捷通道：**【复制到公众号】**（富文本剪贴板直接 Cmd+V）与 **【复制到 Pad】**（Pad 标准格式）
   - 底部辅助通道：**【从剪贴板读取】** 与 **【清除】**

2. **智能识别公众号 / Pad 环境自动直注**：
   - **在公众号页面 (`mp.weixin.qq.com`)**：自动切换为绿色 **【一键注入公众号】**，直接填充正文、标题并触发微信自动保存；
   - **在 Pad / Etherpad 页面 (`*.ifanr.com/pad/*` / `pad.ifanr.com`)**：自动切换为紫色 **【一键注入 Pad】**，直接将标准 Etherpad HTML / Markdown 填入 Pad 编辑器；
   - **在飞书页面**：自动检索后台打开的目标编辑器，一键完成跨标签页内容直注。

3. **100% 原始原图无损直通（彻底解决压缩与裂图）**：
   - 自动切换飞书官方无损全分辨率通道（`preview_type=1` / `preview_type=15` / 原始数据流）；
   - 彻底剥离飞书内部的 `preview_type=16` 缩略图下采样限制；
   - 0 浏览器 Canvas 有损重采样，以 100% 字节对齐的原图 Base64 直通微信编辑器，由微信官方图床托管，展现超清画质！

4. **物理绝对坐标排序（解决开头错位）**：
   - 扫描时精准记录每个内容块在整篇文档流中的物理纵向 Y 坐标（$\text{rect.top} + \text{container.scrollTop}$）；
   - 严格按真实物理绝对高度（$a.\text{top} - b.\text{top}$）排序，无论用户当前停留在文档何处，文章开头 100% 准确呈现！

5. **全量排版规范 100% 对齐 Lark2Pad**：
   - 微信公众号排版：爱范儿 / AppSo 顶部 Banner 动态适配、`<h3>` 标题层级字号与外边距规范、正文 15px/27px 行高、引用块左侧 4px 灰边、图注 12px 浅灰。
   - 文章尾部 Meta 元信息行识别：自动识别作者、编辑、声明、题图等，统一赋予 12px 加粗字体。
   - 微信官方素材防丢失保护：底部 5 斜线橙色分隔符、招聘卡片、二维码素材完整附带 `data-src` / `data-type` 属性，且微信官方图床加入白名单杜绝重转 Base64。

## 🚀 安装与使用

### 1. 安装扩展
1. 下载 Release 中的 `ifanr-layout-extension-v2.0.0.zip` 并解压；
2. 打开 Chrome，访问 `chrome://extensions/`；
3. 打开右上角的 **“开发者模式”**；
4. 点击 **“加载已解压的扩展程序”**，选择解压出的 `extension` 文件夹。

### 2. 日常使用
1. 在飞书文档页面，点击扩展图标打开弹窗；
2. 点击 **【一键读取转换】**；
3. 切换到公众号草稿页点击 **【一键注入公众号】**（或点击 **【复制到公众号】** 直接在草稿里 `Cmd+V` 粘贴）。
